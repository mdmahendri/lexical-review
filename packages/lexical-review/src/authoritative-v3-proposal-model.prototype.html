Which state is the truth?

This throwaway model tests whether version 3 can keep accepted content, immutable revision proposals, mutable proposal drafts, and the live Lexical editor understandable without making Lexical JSON authoritative. Press the buttons freely or follow a guided walkthrough.

Hypothesis: a React-free review document is the only authority for accepted state and independently identifiable proposals. A local authoring overlay owns mutable proposal drafts until export. The Lexical editor is a disposable projection with identity metadata and selection; every semantic input returns to the core before the projection is refreshed.
1. Authoritative review document

Accepted paragraphs, fingerprint, and immutable pending proposals. Pure creation and resolution logic works without React or Lexical.

2. Ephemeral authoring overlay

Proposal drafts and acknowledged replacement intent. Local and mutable; absent from canonical Web Editor Revisions interchange.

3. Live Lexical projection

Rebuildable paragraph and review segments, node keys, and selection. Core IDs travel as node metadata; Lexical keys never escape upward.

keyboard / toolbar / IME / programmatic intent → core transaction → tagged projection refresh

This model intentionally does not settle compound gestures, clipboard transfer, or post-resolution selection; those remain separate Wayfinder decisions. Fingerprints are symbolic in this prototype, not JCS hashes.
