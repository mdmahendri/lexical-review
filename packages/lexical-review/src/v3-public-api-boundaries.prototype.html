Where should the v3 public boundary live?

This prototype tests whether one React-free authoring-session facade can own proposal semantics, native serialization, projections, and WER v1 adapters while a thin client entrypoint owns Lexical event translation, selection recovery, and React registration.

Question being tested: Can Lexical EditorState remain the sole live snapshot mechanism while a narrow ReviewSession facade owns semantic operations and a thin lexical-review/client adapter owns browser input?
Prototype recommendation: publish three entrypoints; extend Lexical snapshots through package-controlled nodes and NodeState instead of creating a parallel review snapshot; make native import/export a validated root contract; isolate version-selected interchange behind lexical-review/wer; use one discriminated outcome vocabulary; and let hosts map explicit rejection commands to their preferred gestures.
